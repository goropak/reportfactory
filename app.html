③ NotebookLM — 슬라이드 & 인포그래픽
보고서가 적용되었습니다. NotebookLM에서 시각적 슬라이드로 변환하세요.
보고서 적용 완료! 아래 버튼으로 NotebookLM을 열고 슬라이드를 만드세요.

📊 NotebookLM 사용법

  1. "슬라이드 지침 + 보고서 복사" 클릭 → 지침과 보고서가 함께 복사됩니다
  2. "NotebookLM 나란히 열기" 클릭 → 오른쪽에 열림
  3. "새 노트북" 만들기 → "텍스트 붙여넣기"로 소스 추가
  4. 좌측 메뉴에서 "슬라이드" 클릭 → 지침에 맞는 슬라이드 생성
  5. 또는 "인포그래픽" 클릭 → 1장 요약 인포그래픽 생성
  6. 생성된 결과를 PDF로 다운로드

⚠️ NotebookLM PDF는 이미지입니다

  1. NotebookLM 슬라이드 PDF는 텍스트가 아닌 이미지로 저장됩니다
  2. Codia AI에서 PPTX 변환 시 "콘텐츠 수정 가능" 옵션을 꼭 활성화하세요
  3. 텍스트 수정이 필요하면 변환된 PPT에서 텍스트 박스를 직접 추가하세요
④ Codia AI — 편집 가능한 PPT
NotebookLM에서 다운로드한 PDF를 Codia AI에 업로드하면 편집 가능한 .pptx로 변환됩니다.
NotebookLM PDF 준비 → Codia AI에서 PPTX로 변환하세요

🎨 Codia AI 사용법

  1. "Codia AI 나란히 열기" 클릭 → 오른쪽에 열림
  2. 구글/이메일로 로그인
  3. "PDF to PPTX" 또는 "Design to PPT" 선택
  4. NotebookLM에서 받은 PDF 파일 업로드
  5. 출력 형식 "PowerPoint (PPTX)" 선택
  6. "콘텐츠 수정 가능" 옵션 활성화
  7. "변환" 클릭 → .pptx 다운로드

⚠️ 참고사항

  1. Codia 무료: 슬라이드 5장까지 변환 가능
  2. 5장 초과 시 유료 결제 필요
  3. 변환 후 맑은 고딕 등 기본 폰트로 확인
